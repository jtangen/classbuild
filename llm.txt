# ClassBuild

> AI-powered course generator that takes a topic and produces a complete, ready-to-teach university course — interactive HTML chapters, gamified quizzes, image-led PowerPoint slides, narrated audiobooks, infographics, weekly mastery challenges and teaching packs — all grounded in five evidence-based learning science principles. Built with TypeScript, React 19, Vite 7, and Claude.

ClassBuild operates as both a browser app (React + Zustand + Vite at localhost:5173) and a headless CLI (`scripts/generate-course.ts`). API keys are bring-your-own: Anthropic Claude (required), OpenAI (optional — gpt-image-2 figures, slide images and infographics) and ElevenLabs (optional — audiobook narration). In the browser, keys stay in localStorage and go only to their own provider.

## Architecture

The codebase has two entry points sharing the same generation core:

- **Browser app**: React 19 SPA with Zustand stores (`src/store/`), Tailwind CSS 4, Framer Motion. Pages follow the pipeline stages: Setup, Syllabus, Research, Build, Export. Course state persists to IndexedDB; a `.classbuild.json` project file saves and restores a course.
- **CLI**: `scripts/generate-course.ts` — headless Node.js script run with `tsx` plus a small `?raw` CSS loader (`scripts/raw-loader.mjs`). Runs the same prompt builders and Claude streaming functions without a browser.

Key directories:
- `src/prompts/` — All LLM prompt builders (system + user prompts for each generation stage)
- `src/services/claude/` — Anthropic SDK client, streaming with retry and refusal fallback, model constants
- `src/services/openai/` — gpt-image-2 image generation and chapter-figure placeholder replacement
- `src/services/elevenLabs/` — Audiobook narration (MP3)
- `src/services/academic/` — Source verification against Crossref, Semantic Scholar and Unpaywall
- `src/services/export/` — PPTX, quiz DOCX, and publish (course site) exporters
- `src/services/quiz/` — Answer balancer for quiz generation
- `src/types/` — TypeScript interfaces for the entire domain model
- `src/themes/` — Six chapter themes (CSS files + `themes.config.ts`) and the narration voice list
- `src/templates/` — Standalone HTML for the practice quiz, weekly challenge, course site and outcomes table
- `src/store/` — Zustand stores: `courseStore` (course state, IndexedDB), `apiStore` (keys, localStorage), `uiStore` (transient)
- `scripts/lib/` — CLI-only helpers: publish assembler, DOCX builders, Node image generation

## Generation Pipeline

The pipeline has five stages, each with dedicated prompt builders in `src/prompts/`:

1. **Setup** (`CourseSetup` type) — User defines topic, audience level, chapter count, theme, teaching environment, and notes.
2. **Syllabus** (`src/prompts/syllabus.ts`) — Claude Opus designs the full course arc. Outputs JSON with chapter titles, narratives, key concepts, widget specs, learning science annotations, and spacing connections. Parsed into `Syllabus` type.
3. **Research** (`src/prompts/research.ts`) — Claude with web search gathers real-world sources per chapter. Produces a `ResearchDossier`; DOIs and metadata are checked against Crossref / Semantic Scholar (`src/services/academic/`).
4. **Build** — Per chapter, generates all materials in parallel where possible:
   - **Chapter HTML** (`src/prompts/chapter.ts`) — Reading in the chosen theme's markup contract, with interactive widgets and gpt-image-2 figure placeholders
   - **Practice quiz** (`src/prompts/practiceQuiz.ts`) — Gamified quiz with confidence calibration
   - **In-class quiz** (`src/prompts/inClassQuiz.ts`) — 5 shuffled versions + answer keys
   - **Discussion questions** (`src/prompts/discussion.ts`)
   - **Activities** (`src/prompts/activities.ts`) — Facilitated activities with step-by-step guides
   - **Audio transcript** (`src/prompts/audioTranscript.ts`) — Narration script sent to ElevenLabs
   - **Slides** (`src/prompts/slides.ts`) — One gpt-image-2 prompt per slide; each slide is a full-bleed 4K image with speaker notes, packed with pptxgenjs
   - **Weekly challenge** (`src/prompts/weeklyChallenge.ts`) — Mastery-gated assessment with 6 question types, parameterised variants, SCORM 2004 wrapper for Blackboard
   - **Infographic** (`src/prompts/infographic.ts`) — Claude writes a prompt, gpt-image-2 renders it
5. **Export/Publish** — Download as ZIP or PowerPoint, package SCORM, or publish a static course site (`src/services/export/publishExporter.ts`; CLI: `scripts/lib/publish.ts`).

## CLI Usage

Keys go in `.env.local` (copy `.env.example`; gitignored), never inline on the command line:

```
npm run course -- \
  --topic "The Psychology of Prejudice" \
  --chapters 12 \
  --level advanced-undergrad \
  --theme terminal \
  --length comprehensive \
  --notes "Use international and Australian examples." \
  --output ./output/prejudice
```

`npm run course` runs `npx tsx --env-file=.env.local --import ./scripts/raw-loader.mjs scripts/generate-course.ts`.

Flags:
- `--topic` (required): Course topic
- `--chapters` (default 12): Number of chapters
- `--level` (default advanced-undergrad): `general-public`, `professional`, `advanced-undergrad`
- `--theme` (default press): `press`, `notebook`, `almanac`, `storybook`, `studio`, `terminal`
- `--length` (default standard): `concise`, `standard`, `comprehensive`
- `--widgets` (default 3): Interactive widgets per chapter
- `--cohort` (default 60): Expected class size
- `--environment` (default lecture-theatre): `lecture-theatre`, `collaborative`, `flat-classroom`, `online-hybrid`
- `--notes`: Additional context for the AI
- `--voice-id`: ElevenLabs voice ID for audiobook narration (defaults to a neutral narrator)
- `--syllabus`: Path to existing syllabus.json (skip regeneration)
- `--stop-after`: `syllabus` or `research` — stop early for review
- `--no-publish`: Skip course viewer assembly
- `--specific-topics`, `--avoid-topics`, `--textbook`: Topic steering and textbook alignment
- `--output` (default ./output): Output directory

Environment variables: `ANTHROPIC_API_KEY` (required), `OPENAI_API_KEY` (optional — figures, slide images, infographics), `ELEVENLABS_API_KEY` (optional — narration). The CLI exits non-zero if any step failed.

## AI Models and Services

Claude models (`src/services/claude/client.ts`):
- `claude-opus-5-5` — Syllabus, chapters, practice and in-class quizzes, weekly challenge. Adaptive thinking with `output_config.effort`, plus a server-side refusal fallback (`fallbacks: "default"`).
- `claude-sonnet-4-6` — Research with web search, slides, discussion, activities, audio transcripts (the `streamMessage` default)
- `claude-haiku-4-5-20251001` — Answer balancing, activity detail, key validation

Thinking levels: `max`, `high`, `medium`, `low` — sent as `output_config.effort` on Opus and as `budget_tokens` (32k/16k/8k/4k) on Sonnet and Haiku.

Streaming (`src/services/claude/streaming.ts`): `streamMessage()` with callbacks for `onText`, `onThinking`, `onToolUse`, `onWebSearch`, `onWebSearchResults`, `onDone`, `onError`; `streamWithRetry()` retries rate limits, overloads and 5xx errors that occur before any output. A response every model declined raises a `ModelRefusalError`.

OpenAI images (`src/services/openai/`): gpt-image-2 renders chapter figures (replacing `<figure class="ai-image">` placeholders), 4K slide images and infographics, as JPEG, with Retry-After-aware retries.

ElevenLabs (`src/services/elevenLabs/tts.ts`): Audiobook narration as MP3, chunked on paragraph and sentence boundaries.

## Core Types

Defined in `src/types/course.ts`:

- `CourseSetup` — Input configuration: topic, level, chapters, theme, environment, notes
- `Syllabus` — Course blueprint: title, overview, array of `ChapterSyllabus`
- `ChapterSyllabus` — Per-chapter plan: title, narrative, keyConcepts, widgets (`WidgetSpec[]`), scienceAnnotations, spacingConnections
- `GeneratedChapter` — All outputs for one chapter: htmlContent, practiceQuizData, inClassQuizData, weeklyChallengeData, discussionData, activityData, audioTranscript, audioUrl / audioDataUri, slidesJson, infographicDataUri
- `ResearchDossier` — Sources per chapter with verification status
- `SlideData` — Individual slide: title, speakerNotes, imagePrompt (rendered to imageDataUri); legacy decks may carry bullets and a layout type
- `EducationLevel` — `high-school`, `first-year`, `advanced-undergrad`, `postgraduate`, `professional`, `general-public`
- `ChapterLength` — `concise` (2k words), `standard` (4k words), `comprehensive` (6k words)
- `SciencePrinciple` — `spacing`, `interleaving`, `retrieval`, `examples`, `dual-coding`
- `BloomLevel` — `remember`, `understand`, `apply`, `analyze`, `evaluate`, `create`

Generation tracking (`src/types/generation.ts`):
- `GenerationStatus` — `idle`, `generating`, `complete`, `error`
- `GenerationProgress` — Stage, chapter number, step, progress percentage, streamed text

## Learning Science Principles

Every prompt instructs Claude to embed these five evidence-based principles:

1. **Spacing** (Distributed Practice) — Key concepts reappear across chapters with increasing complexity. `spacingConnections` in syllabus maps cross-chapter links.
2. **Interleaving** — Related topics from different chapters are mixed in practice and examples.
3. **Retrieval Practice** (Testing Effect) — Built-in "Think About It" prompts and confidence-calibrated quizzes.
4. **Concrete Examples** — Abstract theories grounded in vivid, real-world cases with named people and specific studies.
5. **Dual Coding** — Every concept gets verbal and visual representation through interactive widgets and infographics.

The syllabus stage annotates each chapter with `ScienceAnnotation[]` specifying which principles are emphasized and how.

## Themes

Six chapter themes live in `src/themes/` — each a CSS file plus an entry in `themes.config.ts` — and wrap readings via `renderChapterHtml()`. The app's own UI uses a separate "Codex" design system.

- **Press** — Sunday broadsheet (default): humanities, history, journalism
- **Notebook** — Engineer's graph paper: STEM, maths, problem sets
- **Almanac** — Naturalist's field guide: biology, geography, food, crafts
- **Storybook** — Bold and friendly: languages, intros, K-12
- **Studio** — Modernist monograph: art, architecture, design
- **Terminal** — Dark dev docs: programming, CS, sysadmin, ML

## Voice Options

ElevenLabs premade voices (`VOICE_OPTIONS` in `src/themes/index.ts`): George (default), Daniel, Alice, Lily, Dorothy, Charlie, Brian, Sarah.
